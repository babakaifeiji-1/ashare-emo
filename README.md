# A股短线情绪 + 资金量化系统

数据源: 东方财富网页公开接口(免费、无需账号, 盘中约有几秒到几十秒延迟)。

## 安装

```bash
git clone https://github.com/babakaifeiji-1/ashare-emo.git ashare_emo
cd ashare_emo
python3 -m venv .venv          # 需要 Python 3.9+ (用到 zoneinfo)
.venv/bin/pip install -r requirements.txt
```

## 一键启动 (推荐)

```bash
./start.sh                       # 首次自动建环境装依赖, 然后打开网页看板
# 浏览器访问 http://127.0.0.1:8000
./start.sh --port 9000           # 换端口
./start.sh --host 0.0.0.0        # 局域网/手机访问 (注意: 页面无登录鉴权)
```

一个进程包含全部功能: 盘中每 20 秒刷新(情绪/主线/轮动/资金流/梯队/涨停股评分/买卖信号/持仓盈亏),
买卖信号浏览器提示音, 网页上增删持仓, 15:05 自动生成日报, 15:35 自动 collect, 网页里可查看历史报告.
非交易时间启动会显示最近一个交易日的数据. 下面的命令行子命令仍然可用.

## 命令行用法

```bash
cd ashare_emo
# ===== 盘中实时监控 (直接在终端里跑, 9:15 前启动即可, 非交易时间自动等待) =====
.venv/bin/python -m emo.cli watch                    # 默认 20 秒刷新
.venv/bin/python -m emo.cli watch --interval 10 --stop 4 --core-min 70
# 持仓 (用于卖点提醒; 买入后马上录入)
.venv/bin/python -m emo.cli pos add 601606 30.50 1000 --date 20261015
.venv/bin/python -m emo.cli pos rm 601606
.venv/bin/python -m emo.cli pos ls

# ===== 盘后/分析 =====
.venv/bin/python -m emo.cli rotation                 # 板块轮动(近10日行业涨停数)
.venv/bin/python -m emo.cli today      # 日报: 情绪 + 最强板块 + 情绪票候选 + 主线资金跟风票 (约1分钟)
.venv/bin/python -m emo.cli emotion    # 情绪历史
.venv/bin/python -m emo.cli sectors    # 只看板块强度
.venv/bin/python -m emo.cli backtest   # 回测
.venv/bin/python -m emo.cli collect    # 收盘后跑, 缓存当天数据, 积累回测样本
.venv/bin/python -m pytest -q          # 单元测试
```

报告保存在 `reports/`(包括 Markdown 日报、候选股 CSV 和板块 CSV), 缓存放在 `data/cache/`。

建议的使用时间: 14:30 前后跑一次 `today`, 看尾盘打板机会; 15:30 以后跑 `collect`。
东财的涨停池历史只保留约 20 个交易日, **每天跑 collect 才能把样本攒下来**。

## 盘中买卖点 (`watch`)

每轮刷新约 10 秒(行情延迟 1~4 秒): 涨幅榜前 600 + 涨停/炸板/跌停/昨日涨停池 + 板块 + 持仓.
屏幕显示: 实时情绪/阶段/仓位, 最强主线(含日内高点), 涨停股综合分, 持仓盈亏, 信号流.
所有信号追加写入 `reports/signals_YYYYMMDD.csv`; 出现【买】【卖】时终端响铃.

| 信号 | 级别 | 触发条件 |
|---|---|---|
| 新封板 | 买 | 刚进入涨停池, 封板分 ≥65, 属于前6主线, 非一字; 情绪退潮/冰点或 14:30 后降级为"观察" |
| 炸板回封 | 买 | 上一轮在炸板池, 本轮回封 (分歧转一致) |
| 冲板预警 | 观察 | 距涨停 ≤2.5%, 5分钟涨 ≥1.5%, 量比 ≥1.5, 主力占比 ≥5%, 属主线 —— 准备打板 |
| 主线低吸 | 观察 | 前3主线内涨 2~6%, 主力占比 ≥15%, 站上均价线 |
| 板块异动 | 观察 | 板块约5分钟内涨幅 +1% 且涨停数增加 |
| 止损 | 卖 | 浮亏 ≥5% (`--stop`) |
| 炸板 | 卖 | 持仓涨停被打开 |
| 弱于预期 | 卖 | 10:00 前, 非今日买入, 绿盘且低于开盘价 |
| 止盈 | 卖 | 最高浮盈 ≥15% 后回撤 ≥3% |
| 冲高回落 | 减仓 | 从最高回落 ≥5% 且跌破均价线 |
| 主力流出 | 减仓 | 10:00 后主力净占比 ≤ -10% |
| 板块走弱 | 减仓 | 所属板块从日内高点回落 ≥2% |
| 情绪转弱 | 风险 | 阶段转为退潮/冰点, 或封板率跌破 60% |

| 轮动新进 | 观察 | 板块 15 分钟内从主线外进入前 6, 资金净流入增加且涨幅扩大 |
| 资金加速 | 观察 | 15 分钟主力净流入增量全场最大(≥2亿) |
| 异动带动 | 观察 | 个股异动(5分钟急拉≥3% / 新封板)后 6 分钟, 板块涨幅/上涨占比/涨停数跟随 → 先锋 |
| 孤狼异动 | 观察 | 个股异动但板块不跟; 该股之后的封板买点自动降级为"观察" |
| 主线退出 | 风险/减仓 | 前 6 主线 15 分钟内掉出前 6; 持仓属于该板块时给"减仓" |

同一股票同一信号 30 分钟内只提示一次. 启动后第一轮只建立基线(之前已封板的不会报"新封板").
只有"新封板"的封板分有回测支撑; 其他盘中信号是经验规则, 阈值在 `emo/signals.py` 的 `Config` 中, 建议结合 signals 日志复盘后调整.

## 板块轮动 / 异动带动 / 标的强弱

- **日线轮动** (`rotation`, 面板也显示): 近 10 日每个行业的涨停数 + 走势柱状图, 状态分
  新启动(今日爆发且前3日冷) / 回流(曾热过、冷却后再起) / 加强 / 主升(连续3日以上≥3家) / 退潮(从峰值回落60%+).
  做法: 优先新启动和回流的板块, 回避退潮; 主升板块只做龙头.
- **盘中轮动**: 每个板块的涨幅、主力净流入、上涨占比、涨停数、排名的时间序列, 计算 15 分钟变化, 面板显示资金流入/流出前三.
- **异动带动**: 异动发生时记下板块状态, 6 分钟后评估
  带动分 = 板块涨幅变化(50%) + 上涨占比变化(30%) + 涨停数变化(20%). ≥60 为先锋, <25 为孤狼.
- **标的强弱/梯队**: 前 3 条主线逐只计算
  强度 = 相对板块涨幅 25% + 分时位置 15% + 站上均价 10% + 主力占比 20% + 相对大盘 5 分钟抗跌 10% + 板块内封板次序 20%,
  角色: 龙头(最高板) > 先锋(带动分最高) > 首封(板块第一个封板) > 中军(流通≥200亿且强) > 补涨(前5日涨≤5%今天大涨) > 跟风.

## 模块

| 文件 | 作用 |
|---|---|
| `emo/data.py` | 东财客户端: 个股/板块快照、涨停/炸板/跌停/昨日涨停池、K线、资金流; 重试和镜像轮换; 已收盘数据永久缓存 |
| `emo/emotion.py` | 情绪评分(0-100)和周期阶段, 给出仓位建议 |
| `emo/sectors.py` | 板块强度打分, 按成分股重叠度聚合成"主线" |
| `emo/stocks.py` | 涨停股打分、资金打分、风险标记; 主线内未涨停的资金流入票 |
| `emo/backtest.py` | 两种成交假设下的回测 |
| `emo/signals.py` | 盘中信号引擎(纯逻辑, 有单测) |
| `emo/rotation.py` | 板块轮动(日线/盘中)、异动带动跟踪、个股强弱和角色 |
| `emo/monitor.py` | 实时监控循环、终端面板、持仓 |

## 情绪评分

| 指标 | 权重 | 0分 → 100分 |
|---|---|---|
| 昨日涨停今日平均涨幅(赚钱效应) | 20 | -3% → +4% |
| 连板晋级率 | 15 | 10% → 45% |
| 涨停家数(剔除ST和新股) | 15 | 20 → 120 |
| 封板率 | 10 | 50% → 85% |
| 最高连板 | 10 | 2 → 8 |
| 跌停家数 | 10 | 40 → 0 |
| 大面家数(昨日涨停今日跌超5%) | 10 | 15 → 0 |
| 成交额 / 前5日均值 | 10 | 0.8 → 1.2 |

阶段由今天、昨天、前天三天的情绪分判断: 冰点(≤25)、高潮(≥75); 分数上升 8 分以上, 从低位上来算修复, 从中位上来算发酵; 分数下降 8 分以上, 50 分以上算分歧, 50 分以下算退潮; 变化不大时算混沌。
每个阶段对应的仓位和打法见 `PHASE_ADVICE`。

## 板块强度

在初筛出的 30 个概念板块和 15 个行业板块中, 按以下指标做百分位排名后加权: 涨幅 20、主力净流入额 15、主力净占比 10、上涨家数占比 10、涨停数 20、涨幅超5%的股票占比 10、板块内最高连板 10、近3日涨幅 5。
没有涨停的板块得分乘以 0.6。"融资融券""MSCI"等统计类、风格类板块已过滤。

## 个股打分

- 封板分(core, 只用涨停池数据, 可以回测): 首次封板时间 15、炸板次数 10、封单(封单占流通市值比、封单占成交额比) 15、换手率 10、流通市值 10、所在行业涨停家数 25、连板高度 15。
- 总分 = 封板分 × 0.65 + 主力净占比 × 0.15 + 所属主线强度 × 0.15, 是板块龙头再加 5 分。
- 风险标记: 一字板难买、高位板(≥5板)、反复炸板、尾盘板、北交所、主力净流出、情绪退潮或冰点。

## 回测结果(2026-09-21 ~ 10-14, 12 个交易日, 534 个样本)

**打板模式**(当天以涨停价买入, 次日开盘卖出, 已剔除一字板和秒板, 已扣 0.2% 成本):

| 封板分分组 | 次日开盘卖平均收益 | 胜率 |
|---|---|---|
| Q1(最低) | -0.76% | 32% |
| Q5(最高) | +2.44% | 63% |

- 封板分的 IC 为 0.25。有效的因子是封单、行业涨停家数、封板时间和炸板次数; 换手率、市值、高度三个因子基本无效。
- 每天买封板分最高的 3 只: 平均 +2.8% / 天; 加上情绪过滤(退潮和冰点阶段空仓)后为 +4.2% / 天。

**次日接力模式**(次日开盘买入昨日涨停股, 第三天卖出): 各组都是负收益, 全体平均 -1.7%。
**这就是"追昨日涨停被收割"的量化证据。**

**局限**: 样本只有 12 天; 打板模式假设能以涨停价成交, 实盘排队成交到的往往是封单弱的票, 所以结果偏乐观。
正式使用前, 请用 collect 积累几个月数据后重新回测, 并根据 IC 调整 `CORE_W`、`SCORE_RULES` 的权重。

## 注意

- 东财接口是非官方接口, 字段可能变化; 偶尔有超时, 系统会自动重试并轮换镜像域名。
- 盘中的数据和收盘结果会不同; 盘中成交额是按已交易时间线性外推的。
- 本系统是量化辅助工具, 不构成投资建议。
